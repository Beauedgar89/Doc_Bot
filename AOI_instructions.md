## 2 Intended Use

The ifm\_O2D5\_O3D3\_Vision Add-On Instruction provides a logical user interface to the O3D3xx sensor.

The Add-On Instruction is to be integrated in a PLC program to:

1. Provide evaluation results
2. Switch applications
3. Display application information
4. Request pass/fail statistics
5. Process errors

Logical integration of the Add-On Instruction is aided by its output tags. The outputs tags Camera Ready, Command Busy and Command Done provide the logic states of the O3D3xx sensor so the user controlled functions can be utilized with minimal processing outside the Add-On Instruction.

## 7.3 Trigger Modes: Continuous\_HW\_Trigger

After the Get Application Info command has completed, the ifm\_O2D5\_O3D3\_Vision Add-On Instruction monitors for any triggering of evaluations.

## Process Interface Trigger applications:

If the configuration of the O3D3xx sensor is set to Process Interface: Continuous\_HW\_TrigMode output is set FALSE.

## Continuous or Hard-Wired Trigger applications:

If the O3D3xx 's trigger configuration is set to Continuous:

Continuous\_HW\_TrigMode output is set TRUE after the O3D3xx is set to monitor mode and the first evaluation is processed.

If the O3D3xx trigger configuration is set to Positive Edge, Negative Edge or Positive and Negative Edge: Continuous\_HW\_TrigMode output is set TRUE after the first edge-controlled evaluation is processed.

The Continuous\_HW\_TriggerMode output will hold TRUE until:

1. The Change Application command is processed by the rising edge of ChApp\_Trigger.
2. The Get Application Information command is processed by the rising edge of GetAppInfo\_Trigger.
3. An Ethernet/IP communication fault.
4. The sensor is rebooted.

## Vision Assistant Test operations:

The last step in the Vision Assistant configuration of the O3D3xx is Test operations. In Test operations the O3D3xx sensor behaves as it would in Monitor mode to the PLC.

If the trigger configuration is set to Process Interface and the Vision Assistant's evaluation button is utilized by the user, the Add-On Instruction interprets the evaluation 's source to be from a continuous or hardwired trigger and the Continuous\_HW\_Trig output will be set TRUE.

When the O3D3xx is set back to monitor mode, the Get Application Info command must be executed to refresh the Continuous\_HW\_TrigMode output so the Eval\_Trigger may be used. See section 7.4.8 for an explanation of the Get Application Info command.

## 7.4.4 Done Outputs -GetAppInfo\_DN, Eval\_DN, ChApp\_DN, GetStatistics\_DN or GetError\_DN

There are five done outputs from the ifm\_O2D5\_O3D3\_Vision Add-On Instruction.

1. GetAppInfo\_DN
2. Eval\_DN
3. ChApp\_DN
4. GetStatistic\_DN
5. GetError\_DN

Initial setting of all xxxx\_DN outputs:    =FALSE

Command processing complete:

xxxx\_DN

=TRUE

The following conditions will reset the one or more done outputs:

1. If any done output is true, it will be set false on the rising edge of its associated trigger.
2. The rising edge of the ChApp\_Trigger will set the ChApp\_DN, GetAppInfo\_DN and GetStatistic\_DN outputs false.
3. If the O3D3xx loses Ethernet communication or is rebooted, all done outputs are set false.

## 7.4.5 Triggers

There are five triggers available in ifm\_O2D5\_O3D3\_Vision Add-On Instruction:

1. GetAppInfo\_Trigger
2. Eval\_Trigger
3. ChangeApp\_Trigger
4. Get\_Statistics\_Trigger
5. Get\_Error\_Trigger

A rising edge of a trigger starts the processing of its associated command if the Camera\_Cmd\_Rdy output is true.

A trigger input may be reset to false before the command is done processing; i.e., it can be used with a ONS instruction.

If multiple triggers are set true in the same PLC scan no commands are executed.

## Multiple triggers set true:

1. If a trigger is true, no command is processing and another trigger is set true, then no command is executed.
2. If a command is in process and one or more triggers are set true, the command in process will finish and no new commands will be executed.

In both of the above cases, all triggers must be set false before the Add-On Instruction will execute another command.

## 7.4.6 Process Interface (Ethernet/IP) Trigger: Eval\_Trigger

The rising edge of the Eval\_Trigger sends a process interface (Ethernet/IP) trigger command to the O3D3xx sensor. The sensor will perform an evaluation as configured by the Vision Assistant. When the Evaluation command is complete:

Eval\_DN

=TRUE

Eval\_Result

=data array is updated

## 7.4.7 Evaluation Results: Eval\_Results

The evaluation results are updated after a process interface (Ethernet/IP) trigger command has completed processing. The Eval\_Results is a data array of integers with a size of 221. The Eval\_Result data array mapping is configured by the Process Interface section in the Vision Assistant.

## 7.4.8 Get Application Information: GetAppInfo\_Trigger

The rising edge of the GetAppInfo\_Trigger processes the get application information command. The command will set the ActiveAppNumber and TotalNumApps values.

The command is automatically executed by the Add-On Instruction if the following conditions are met:

1. On a first scan of the PLC. See section 7.1 for a description of when the first scan is applicable.
2. After a change application command is completed, the Add-On Instruction will execute a GetAppInfo command.
3. The O3D3xx loses Ethernet communication or is rebooted.

The command should be executed by the user if any of the following changes are made using the Vision Assistant and the O3D3xx is set back to Monitor Mode:

1. Addition of an application.
2. A change to the active application.
3. The Trigger mode of an application is changed.
4. When in the Test operations of an application in which the trigger configuration is set to Process Interface and the evaluation button is used to trigger the O3D3xx. See section 7.3 for more detail.

## 7.4.9 Set Application Number: SetAppNumber

The O3D3xx 's application numbers are assigned by the Vision Assistant. Up to 32 applications may be saved on the O3D3xx sensor. The ifm\_O2D5\_O3D3\_Vision Add-On Instruction may be used to switch active applications. The SetAppNumber is the application number to be made active after a change application command is executed.

## 7.6 User input errors: AOI\_Settings\_Error

If the AOI\_Settings\_Error is true, then at least one user input of the ifm\_O2D5\_O3D3\_Vision Add-On Instruction is out of range or incorrectly set. When the user corrects the error, the AOI\_Settings\_Error will be false.

The following cases will cause an AOI\_Setting\_Error to be true:

1.  The SetAppNum = ActiveAppNumber and the user sets the ChangeAppTrigger true.
2. GetApp\_DN is true and the SetAppNum&gt;TotalNumApps.
3. SetAppNum&lt;=0. A negative value and zero are invalid application numbers for the O3D3xx. The AOI\_Settings\_Error will be set false if GetApp\_DN is false and SetAppNum &gt;0 and &lt;=32. 4. SetAppNum&gt;32. The O3D3xx 's maximum number of memory locations is 32.
5. The Eval\_Trigger is true while the Continuous\_HW\_TrigMode output is true.
